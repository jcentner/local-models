# Needle 2 household fine-tune — can a 14MB model defer the talos GPU?

**Status: staged — no weights pulled, nothing run.**

## Hypothesis

A LoRA fine-tune of [Needle 2](../../../wiki/models/needle2.md) (45M, 14MB,
CPU-only) on a synthetic household tool-calling dataset can handle the
*routine* single-shot slice of Iris's actuation surface on **talos's CPU**
(i7-12700K, 16GB cap, no GPU — olympus FLEET.md), with a **measurably
calibrated confidence head** gating everything else up to the API model
(GPT-5.6 Luna). If true, this defers the "talos gets a GPU" decision and cuts
metered-API traffic; if the confidence head is uncalibrated, the whole
pattern dies regardless of accuracy — so calibration is a first-class result,
not a footnote.

Secondary hypothesis (from HN evidence): the stock model's negation blindness
("do not lock the door" → locks it) and off-topic actuation are floor
behaviors a domain fine-tune + confidence threshold can lift. Measure
before/after on identical traps.

## Method (staged)

1. **Bring-up** (torrent): `python3 -m venv .venv && .venv/bin/pip install
   cactus-needle`; smoke the stock model + `needle playground`. Record
   version, actual RAM, CPU tok/s.
2. **Probe set** (authored, before any tuning): ~60–100 single-turn prompts
   over an Iris-shaped household toolset (thermostat, locks, lights, garage,
   water shutoff — align with the homeview 37-type asset library where
   sensible). Classes: clean actuation, arg-fill precision, **negation traps**,
   **off-topic/garbage**, **ambiguity traps** (correct answer = low-confidence
   empty call), unknown-requester refusals (Iris's deny-by-default idiom).
   Separate answer key per repo benchmark conventions. Score = exact
   function+args match; plus per-item confidence recorded.
3. **Baseline**: stock Needle 2 on the probe, k=3 (flakiness per
   [eval-reliability](../../../wiki/concepts/eval-reliability.md)).
   Deliverables: accuracy by class + **reliability curve / ECE** for the
   confidence head + a chosen operating threshold and its precision/recall.
4. **Dataset synthesis**: ~1–5k examples, generated by **GPT-5.6 Luna**
   (cheap + already the Iris model; rides the capped Iris OpenAI key — Jake
   OK'd 2026-08-14, flag spend; alternative: sanctioned Copilot path). NOT
   the package's built-in OpenRouter synthesis (API-key policy). Same tool
   schemas as the probe; include negation/off-topic/refusal negatives.
   Probe stays held out.
5. **Fine-tune** (torrent GPU, JAX CUDA): LoRA per the needle docs; export
   merged `.cact` (2-bit and 4-bit variants if cheap).
6. **Re-run probe** on the tuned model, same k. Before/after accuracy by
   class + calibration.
7. **talos deploy check**: copy the `.cact` + venv to talos, measure CPU
   tok/s, RAM, and latency per call inside the 16GB-cap reality.
